# 当前 RAG 问答小样本诊断（2026-11-04）

## 测试范围

使用现存 QASPER test 30 篇论文索引 `m6_qasper_test30_20261018`（1,062 个片段），未重新建库。按固定种子 20261104，从其中选择 15 道有答案且有可映射正文证据的问题、3 道所有标注均为不可回答的问题；将前 12 道有答案题两两组合成 6 道跨论文复合问题。因此这是 **24 次查询、18 个不同原始问题**，6 道跨论文题由我们构造，并非 QASPER 官方多论文评测。

本次使用当前 `RAGReader / AnswerGraph / EvidenceGraph`、Milvus dense 候选 20、BGE reranker、Top-5、balanced 多论文取证，以及本机 Qwen3-4B；过度拒答的严格门控关闭。评测直接调用 RAG 核心图，不经过 FastAPI、MySQL、UI、会话改写或 PDF 解析。QASPER 是结构化论文文本，不验证 PDF 页码。参考答案与证据只用于抽样和事后评分，不进入模型问题或检索文本。此 30 题索引此前参与过项目检索实验，结果用于开发诊断，不能作为未见论文的最终成绩。

## 结果

| 指标 | 结果 | 理解方式 |
| --- | ---: | --- |
| 执行完成 | 24/24 | 无执行失败，不代表回答正确 |

| 多论文题引用覆盖 | 6/6 题均引用两篇 | 只检查引用属于两篇，不能证明引用支持回答 |

真实本地模型调用的记录合计输入约 33,675 token、输出 4,417 token，不涉及收费模型 API。对于不可回答题，直接计算的英文 `Unanswerable` 词面 F1 均为 0，但其中两道回答语义上明确表示无法确定；不能把这一数字当成拒答错误。

证据命中代理有假阴性：`single_03` 的标注段落未达到代理阈值，但引用的论文结论也明确支持模型的 “No”。因此下面的命中标记只是定位线索，引用支持和事实正确仍需按原文语义检查。

## 下一步建议

1. 在独立留出论文中优先核查多论文问题：比较整句检索与按论文拆分检索，固定向量、重排器和证据预算，分别看每篇证据命中及耗时。当前六道多论文题太少，不能只据此上线。
2. 增加针对结果对象、指标及差值的回答对照；`single_02` 和 `multi_06` 说明即便引句含有原始数字，生成仍可能混淆含义。
3. 增加本研究与相关工作区分的对照；`single_15` 是具体候选错例。
4. 不可回答题需要更多经复核样本；`unanswerable_02` 暴露标注与正文可能不一致，不能用 3 题推断可靠拒答率。

固定题单、逐题答案与所有模型看到的片段保存在被 Git 忽略的 `evaluation/runs/local_diagnostic_20261104/`；`cases.json` 包含参考，`results/` 保存每题原始结果，`scored_cases.json` 保存词面分和证据命中代理。可复跑脚本为 `evaluation/local_diagnostic_20261104.py`；运行结果与原索引清单均保留，未覆盖历史实验。本机 Qwen 和本轮启动的 Milvus 服务在测试后已停止。
