# QASPER 第三、四阶段结果：证据选择与新论文验证

日期：2026-10-22。实验口径在[预先锁定的协议](QASPER_PHASE34_PROTOCOL_20261022.md)中。全部实验调用本机 Qwen3-4B；没有使用 DeepSeek 或其他付费 API。正式问答链路的默认 Top-K、AnswerGraph 和提示词均未修改。

## 数据边界

- 旧开发集：此前调试过的 QASPER dev 200 题、以及同 151 篇论文上的新问题 60 题。它们用于找原因和选择要验证的候选，不当作新论文结果。
- 新论文验证集：固定种子抽取此前核心评测未入库的 30 篇 dev 论文，其全部 79 道题；与旧 151 篇无交集。冻结清单在 `evaluation/fixtures/qasper_new_papers_20261022.json`，SHA-256 `0e6022bf6db23f106e5afc4be4b6f2f562cb43dc4e77bbdba3f760975ab0c5e8`。索引为隔离 Milvus 集合 `eval_current_qasper_new_papers_20261022`，30 篇共 1,304 个片段。
- 本轮用 QASPER 结构化 `full_text`，没有运行 PDF 解析器。对照覆盖 BGE-M3、Milvus dense20、BGE reranker、Top-5、Qwen 简答；它是组件测试，不能直接代表完整 FastAPI/LangGraph 产品链路。
- 标准答案和标准证据只用于事后评分，没有进入建库文本、检索、选证据或问答请求。所有原始请求哈希、响应、格式状态、用量和耗时均留在 `evaluation/runs/`，已有结果未被覆盖或自动补答。

## 第三阶段：按原因逐项对照

在旧 200 题中，175 题有可映射到结构化正文的标注证据。直接在固定的 BGE Top-10 排名中换第 5 个片段：

| 证据选择 | 正文标注证据命中@5 | 相对基线找回/丢失 |
|---|---:|---:|
| 原始 BGE Top-5 | 134/175 | — |
| 词面匹配尾部候选 | 131/175 | 0/3 |
| 章节多样性尾部候选 | 131/175 | 0/3 |
| Qwen 从 Top-10 选 5 | 135/175 | 12/11 |

只有 1 题的净增益，且 Qwen 选择会造成大量互换。1 篇短论文不足 10 个候选时按预设回退 Top-5。旧 60 题上，Qwen 选择让证据命中从 29/42 到 31/42，Answer F1 从 0.218 到 0.283，但 Evidence F1 从 0.428 降到 0.382；不可回答题的非标准非空输出从 6/12 增到 7/12。它可以改善某些题的简答，也会丢掉原来有用的证据，不能根据旧题直接上线。

针对回答侧的两个独立提示词对照也只在旧 60 题进行，均固定原 Top-5：

| 回答提示词 | Answer F1 | Evidence F1 | 有答案题拒答 | 格式合格 |
|---|---:|---:|---:|---:|
| 原 v3 | 0.218 | 0.428 | 10/48 | 57/60 |
| 明确区分本论文与相关工作 | 0.229 | 0.390 | 11/48 | 57/60 |
| 明确核对数字的对象、指标和单位 | 0.276 | 0.467 | 14/48 | 59/60 |

“相关工作”指令没有带来稳健提升，因此没有进入新论文验证。数字指令虽然提高旧题总体 F1，却让有答案题多拒答 4 道；按问题文字关键词圈出的 6 道数字相关题，平均词面 F1 还从 0.040 降至 0.028。总分提升**不能解释为数字比较能力提升**。该数字提示词在新论文答案评分之前被锁定，作为第二个候选单独验证；没有与 Qwen 选证据组合。

第二阶段的引句门控此前已证明过度拒答，故本轮没有把它作为正式修复接入；本轮也没有把 QASPER 的英文 `Unanswerable` 规则直接放进中文产品。

## 第四阶段：30 篇新论文、79 题固定验证

79/79 题的检索和每组问答请求均完成。基线 Top-5 的正文标注证据命中为 46/68；相同 BGE 排名的 Top-10 为 56/68。另 11 题没有可映射到结构化正文的标注证据，不纳入该命中率分母。标注类型分布：抽取式 31、摘要式 15、是非题 10、一致不可回答 4、标注者类型不一致 19。不可回答题太少，相关计数的统计不稳定。

| 方案 | Answer F1 | Evidence F1 | 正文命中@5 | 非标准非空输出/一致不可回答题 | 有答案题拒答 | 格式合格 | 平均检索＋额外选择＋回答 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 原 Top-5 基线 | **0.358** | 0.363 | 46/68 | 2/4 | 9/56 | 75/79 | 18.68 秒 |
| Qwen 选证据 Top-5 | 0.330 | 0.357 | 48/68 | 3/4 | 8/56 | 77/79 | 21.02 秒 |
| 数字核对提示词、原 Top-5 | 0.355 | **0.417** | 46/68 | 2/4 | 12/56 | 76/79 | 18.67 秒 |

Qwen 选证据在正文命中上净多 2 题：找回 10 题、丢失 8 题。找回的 10 题中，只有 4 题 Answer F1 提升，3 题下降、3 题持平；丢失的 8 题中有 5 题 F1 下降。全部 79 题逐题配对为 15 题提高、21 题下降、43 题持平。额外选择平均花 2.32 秒，输入约 1,881 token/题；总体回答 F1 低于基线。

数字提示词的 Evidence F1 更高，但 Answer F1 没有改善，有答案题拒答增加 3 道。79 题逐题配对为 10 题提高、9 题下降、60 题持平。按问题关键词圈出的 10 道数字相关题，平均词面 F1 从 0.241 降到 0.204；这仍不能证明其数字核对能力更好。

按论文 ID 做 5,000 次重采样的探索性 95% 区间：Qwen 选证据相对基线 Answer F1 差值约为 `[-0.070, +0.017]`，数字提示词约为 `[-0.038, +0.039]`。区间跨零，样本规模不支持稳定收益结论。温度 0 的本地模型仍可能有少量输出波动，本轮每题只生成一次。

**接入决定：两项候选都未通过预设条件，正式系统保持当前默认链路。** Qwen 选证据没有提高 Answer F1，还提高了错误作答风险代理指标与耗时；数字提示词没有提高 Answer F1，且过度拒答增加。旧题上看起来有效的方案，在新论文上没有复现。

## 指标与后续边界

QASPER Answer F1 是词面重合，不等于事实正确率。Evidence F1 与正文命中使用标注段落投影，不能证明引用在语义上支持答案。“非标准非空输出”中可能存在语义拒答，不能机械当成编造；4 道一致不可回答题尤其不能支撑可靠的错误作答率估计。19 道混合标注题也应单独看待。要宣称事实与引用正确率，需要人工核对原文或另建独立的可验证事实集。

下一轮不应继续在这 30 篇论文上调整同一候选。若要优化，优先研究 Top-10 已有证据却最终未被可靠选中以及“证据进入上下文后仍未用对”的原因；新的参数或提示词需要再次按论文 ID 预留新验证集。表格、公式与 PDF 解析问题应使用原始论文 PDF 单独评测。

只读复核入口：

```powershell
python -m evaluation.qasper_paper_holdout
python -m evaluation.qasper_phase3_selection --cohort new_papers --include-model
python -m evaluation.qasper_phase34_answers score --cohort new_papers --variant baseline5
python -m evaluation.qasper_phase34_answers score --cohort new_papers --variant model_selected5
python -m evaluation.qasper_phase34_answers score --cohort new_papers --variant numeric_guard5
python -m evaluation.qasper_phase34_compare --cohort new_papers --candidate model_selected5
python -m evaluation.qasper_phase34_compare --cohort new_papers --candidate numeric_guard5
```

这些命令读取已有响应并重算评分，不重新请求模型。完整建库与检索分别由 `evaluation.qasper_new_paper_runtime index` 和 `retrieve` 在项目 Python 容器中执行；Qwen 请求入口分别是 `evaluation.qasper_phase3_model_selection` 与 `evaluation.qasper_phase34_answers run`，应在新目录下运行以避免混淆原始结果。
