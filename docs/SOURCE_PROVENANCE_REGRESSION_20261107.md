# 来源与证据修复回归（2026-11-07）

## 问题和改动

原先的真实双论文问答把机器人综述的参考文献当成论文自身的研究证据。QASPER 结构化原文的章节名也在转成平面文本后被猜测规则误覆盖。现在：

- QASPER 数据源保留官方 `abstract` 和 `full_text` 的章节结构；只用论文原文建库，不把问答标准答案送入索引。索引片段记录来源版本。
- Docling 解析出的书目条目标记为 `References`，并保存原章节和原始位置；正文段落不随相邻书目一起改标。
- 回答模型收到论文标题、证据类型、页码、章节及片段。只传这些白名单字段。
- 问题询问论文自身的任务或贡献时，重排前排除书目与孤立标题；参考文献查询保留书目。若单篇论文过滤后少于两条候选，进行一次限定该论文的补充检索。

## 验证和限制

来源与检索定向测试 14 项通过；完整离线测试 **543 项通过、27 项按条件跳过**。旧索引的原有错误章节仍存于 Milvus；查询时会根据片段文本与章节补判来源，持久化修复需要重新入库论文。一次补检会增加少量检索耗时，本轮未做延迟基准。当前“证据充分”门槛仍主要检查每篇论文的片段数量，尚不能保证每个结论都被语义支持。
