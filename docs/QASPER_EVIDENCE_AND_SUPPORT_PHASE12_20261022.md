# QASPER 证据预算与回答支持性实验（第一、二阶段）

日期：2026-10-22。实验使用本机现有 Milvus 索引、BGE 重排模型和 Qwen3-4B。答案与支持性核对没有发送到第三方 API。原始记录保存在 `evaluation/runs/qasper_followup_20261022/evidence_budget/` 和 `support_experiment/`，此前的 200 题、60 题基线仍保留。

## 实验设计

- 对先前冻结的同一批 dense 前 20 候选按 ID 重新获取片段，使用相同 BGE reranker 一次排序，从该排名取 Top-5、Top-8、Top-10。60 题的重新排序 Top-5 与旧版保存的 Top-5 **60/60 顺序完全相同**，所以 Top-5 答案直接复用原始模型响应。
- 原 200 题也按相同方法完整重新排序，保存结果与原始 Top-5 **200/200 顺序完全相同**；这排除了重跑时排序漂移造成的伪增益。
- `merge8` 只合并 Top-8 中同论文、同页、同章节、编号连续的已选片段；不偷加未检索片段。评价证据命中时仍按原始组成片段投影，以免段落跨边界导致合并后被字符串匹配器误判为丢失。合并后的引用 ID 是实验用组合 ID，不能直接用于正式原文定位。
- 回答实验对每个变体使用同一 v3 英文简答提示词、同一批 60 个问题、本地 Qwen、温度 0。Qwen 温度 0 曾观察到少量输出波动；数值是一次运行结果。
- 支持性实验先检查标准/非标准拒答及引用存在性，再让本地 Qwen 只看回答及被引用片段，判断其是否直接支持回答；模型声称“支持”时，还必须给出能在被引用片段中逐字找到的引句。未通过者回退为 `Unanswerable`。回退变体只允许把证据扩展到同一候选排序的 Top-8 并重新回答、核对一次。
- 标准答案、标准证据、题型只进入评分器，不进入检索、回答或支持性核对请求。

这 60 题已经在上一轮提示词分析中被查看。本轮是**同题受控开发实验**，不能再次称作独立盲测；所有候选方案都需在尚未参与调试的论文 ID 上重新验收后才可作正式能力声明。

## 第一阶段：证据预算

先看完整 200 题。175 道有可映射到结构化正文的标准证据，以下命中率均以 175 为分母；200 题均完成了本地只读重排。

| 方案 | 正文证据命中 | 平均输入字符 | 平均上下文片段数 |
|---|---:|---:|---:|
| Top-5 | 134/175（76.6%） | 4,490 | 5.00 |
| Top-8 | 142/175（81.1%） | 7,063 | 8.00 |
| Top-10 | 147/175（84.0%） | 8,707 | 9.99 |
| 相邻片段合并后 Top-8 | 142/175（81.1%） | 6,919 | 6.02 |

Top-8 比 Top-5 多找回 8 题，Top-10 再多 5 题；代价是平均输入字符分别增加约 57% 和 94%。相邻片段合并不增加证据覆盖，只减少片段包装字段和少量字符。此前 dense 前 20 候选命中 161/175，说明排序后 Top-10 仍遗漏 14 道候选中已有证据的题。

60 道新问题中，42 道有可映射到结构化正文的标准证据。下表命中率分母固定为 42；输入与生成开销分母为全部 60 题。

| 方案 | 证据命中 | 平均输入字符 | Answer F1 | Evidence F1 | 平均输入 token | 平均回答耗时 | 格式合格 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Top-5 | 29/42 | 4,546 | 0.218 | 0.428 | 1,516 | 1.69 秒 | 57/60 |
| Top-8 | 35/42 | 7,093 | 0.207 | 0.357 | 2,138 | 2.41 秒 | 58/60 |
| Top-10 | 36/42 | 8,736 | 0.211 | 0.351 | 2,546 | 2.83 秒 | 57/60 |
| 相邻片段合并后 Top-8 | 35/42 | 6,934 | 0.227 | 0.310 | 2,075 | 2.96 秒 | 53/60 |

Top-8 比 Top-5 多覆盖 6 道正文证据题，但总体 Answer F1 下降、输入约增加 41%、生成耗时约增加 43%。Top-10 仅比 Top-8 再多覆盖 1 题。合并 Top-8 后输入 token 仅减少约 3%，其 F1 略高于 Top-5，但格式错误从 3 条增为 7 条，引用段落投影分数更低，还会改变可定位的来源 ID。**因此当前不调整正式系统的 Top-K，也不接入合并片段。**

逐题配对时，Top-8 相比 Top-5 有 11 题 F1 提升、10 题下降、39 题持平。在新找回标注正文证据的 6 题里，也只有 1 题 F1 提升、1 题下降、4 题不变。证据进入上下文后，模型是否正确利用证据仍是独立瓶颈。

这些回答对照是已经看过的 QASPER dev 论文上的探索结果，不是新论文验证。证据命中是段落字符串投影，不能证明语义支持；Evidence F1 也不能替代人工核对引用。

## 第二阶段：回答支持性与一次回退

下表中的“具体作答”按人工复查后的语义区分：原 v3 的 6 条非标准非空输出里有 2 条实际是在说“片段没给出答案”，所以原始真正给具体内容的是 4/12。其余 3 条格式无效单独保留，不算具体作答。所有比例仅与 QASPER 这 60 题的标注相比，尚非事实正确率。

| 策略 | Answer F1 | 不可回答题给具体内容 | 有答案题拒答 | 额外核对/回退 |
|---|---:|---:|---:|---|
| 原 v3 Top-5 | 0.218 | 4/12（另有 2 条非标准拒答句） | 10/48 | 无 |
| 只统一无引用拒答句 | 0.250 | 4/12 | 11/48 | 纯文本规则，3 条被规范化 |
| 引句核对；未通过即拒答 | 0.291 | 1/12 | 24/48 | 41 次本地核对 |
| 引句核对；未通过时扩至 Top-8 再试一次 | 0.267 | 4/12 | 19/48 | 19 题回退，其中 17 次再次核对 |

引句核对能减少不符合“不可回答”标注的具体作答，但明显增加了有答案题的拒答。扩大证据范围能找回部分答案，也重新带来不符合标注的具体作答。精确引句只证明文字存在于片段，**不证明该文字在语义上支持整句回答**；本次就观察到模型能引用原句，却仍可能把相关工作或不完整证据当成答案。因此门控组件已作为实验代码保留，**没有接入正式 AnswerGraph，也没有改动默认问答行为**。

单纯的拒答句规范化收益属于评分格式改善：它把“片段未说明”之类无引用句统一为 `Unanswerable`，不能表述为模型理解能力提升。正式产品使用中文回答，不能直接照搬本轮英文数据集规则。

## 结论与下一步验收

第一阶段证实了候选到最终证据之间存在排序/预算损失，但在这批题上直接扩大 Top-K 会带来更高开销和更低回答 F1。第二阶段证明了当前引句核对过于保守，且一次 Top-8 回退不能保持低错误作答率。下一次改进应把“定位含答案片段”与“答案是否被该片段蕴含”分开评测，并在尚未参与调试的论文 ID 上验证，达到回答质量、错误作答和耗时均可接受后再接入正式流程。

复查入口：

```powershell
python -m evaluation.qasper_evidence_budget score-retrieve --cohort holdout60
python -m evaluation.qasper_evidence_budget score-retrieve --cohort 200
python -m evaluation.qasper_evidence_budget score-answer --cohort holdout60 --variant top5
python -m evaluation.qasper_evidence_budget score-answer --cohort holdout60 --variant top8
python -m evaluation.qasper_evidence_budget score-answer --cohort holdout60 --variant top10
python -m evaluation.qasper_evidence_budget score-answer --cohort holdout60 --variant merge8
python -m evaluation.qasper_support_experiment score-normalize
python -m evaluation.qasper_support_experiment score
python -m evaluation.qasper_support_experiment score --retry
```

上述评分命令均只读保存的结果，不调用本地模型或外部 API。
