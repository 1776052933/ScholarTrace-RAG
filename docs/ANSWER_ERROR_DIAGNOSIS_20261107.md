# 两个回答错例的诊断（2026-11-07）

本轮只读取已保存问答、QASPER 原始数据、解析文本与当前代码，并运行章节识别复现。未调用生成模型、修改业务逻辑或重新建立索引。诊断脚本：`evaluation/diagnose_answer_errors.py`；带原始证据和文件 SHA-256 的记录：`evaluation/runs/error_diagnosis_20261107/diagnosis.json`（本机忽略目录）。

## 1. 综述被误述为具体实验：参考文献进入回答证据

原问题要求比较 Transformer 与灵巧操作综述各自研究的任务。Qwen 回答后者研究软体机械手从人类示范学习。已保存回答中，属于综述的三条引用全部是第 15 页的书目条目：Gupta 等（2016）、Bicchi（2000）和 Chen 等（2021b）。其中 Gupta 条目的题名正是 “Learning dexterous manipulation for a soft robotic hand from human demonstrations”。模型将被引用论文的题名归到了当前综述本身。

综述的本地解析文本 `data/repro_acceptance_20261102/runtime/papers/text/1600c12fbcc52d8f.txt` 在第 41、67、69 行明确说明文章综述多指机械手灵巧操作、强化学习及其发展。第 371 行可找到被模型误用的 Gupta 书目条目。

已确认的问题：

- 这些书目条目进入了实际提供给模型的证据并被引用。现有检索/重排主要按问题相关性选片段，缺少对书目条目与本文正文的用途区分。
- 三条引用的 section 都是 `FUNDING`。解析文本在 `REFERENCES` 后又混入正文尾部、结论和经费段，随后接续书目条目。`DoclingPDFParser.parse` 按遍历顺序继承最近标题，存在将后续条目标成 FUNDING 的风险。保存结果已证实标签错误；精确到原始 Docling item 的产生路径仍需保留结构化解析记录复查。
- `_fit_evidence` 实际只向模型传递 `chunk_id/paper_id/page/section/text`；论文标题和 Docling `item_type` 未进入该输入。非流式多论文问答的外层 payload 也没有论文标题表。
- `EvidenceGraph._assess` 以每篇至少两条片段判断 coverage。书目条目也计入数量，因此目前 `sufficient` 表示覆盖数量满足要求。
- 默认 `_parse_answer` 校验 JSON、引用 ID 并组装引用；引用存在并不会触发逐项事实归属检查。这次 0.9 的 confidence 来自模型输出。

原始完整多论文 prompt 和未引用片段未保存在该回归报告中，本轮只对已保存引用作确定判断。仅凭这份报告无法断言当时完全没有提供综述正文，也不能把未引用片段重构为原始输入。

结论：这个错例同时包含**证据选择不合适、章节标签错误和模型归属判断错误**。上轮“优先看生成环节”的建议需要据此调整，先检查证据来源结构。

## 2. 数据集语言误答：正确证据已在第一位

QASPER 问题 ID：`1e775cf30784e6b1c2b573294a82e145a3f959bb`，论文 ID：`1909.13104`。

问题是数据集包含什么语言。两份参考答案都是 English。当前回答是 English、German、French、Greek；旧答案是 English。

Top-1 `1909.13104-chunk-00016` 的完整文字明确描述：先将英语推文翻译成德语、法语和希腊语，再译回英语以增强数据。模型把过程中的中间语言当成最终数据集语言。新旧 Top-5 的 ID、顺序和文本逐项相同，关键句完整位于提供给模型的片段中，能够支持正确回答。

另发现一个可直接复现的结构问题：QASPER 原始 `full_text.section_name` 是 `Proposed methodology ::: Data augmentation`，但保存片段的 section 是 `Related Work`。当前评测适配器先将结构化正文平铺成文字，随后切分器用有限的标题识别规则重新推断章节；它能识别 Related Work，却没有识别 Dataset description、Proposed methodology ::: Data augmentation 等标题，导致错误继承旧标签。对原始正文直接调用当前 `_section_blocks` 已复现该结果。

结论：**该题无需增加召回数量，关键事实已经检索到；主要错误是最终对象与处理中间对象的混淆。** 错误章节标签是同时确认的输入缺陷，其对本题回答的实际影响尚待单因素对照。新旧答案变化的成因仍需同一运行环境、同一完整请求的重复调用确认。

## 后续修改优先级与验证方式

1. **先修结构与来源信息。** QASPER 保留官方章节边界；PDF 保留可靠的条目类型、标题和来源标记，处理跨栏阅读顺序造成的章节继承问题。标题/条目类型在回答输入中可见。复测章节归属与输入预算；涉及切片或索引变化时建立独立候选索引，保留旧库。
2. **再做书目证据选择对照。** 对“本文研究什么、提出什么、得到什么结果”等问题，候选方案优先选择摘要、引言和结论正文，并避免单靠书目条目描述本文贡献。参考文献保留用于“引用了谁”等问题。先只改变这一因素，观察综述错例、正文证据占比、引用质量和延迟。
3. **最后做生成归属约束对照。** 固定证据，尝试一句通用规则，要求区分本文与被引用研究、目标对象与处理中间对象；避免把具体语言名称写进提示词。同时检查拒答与已有正确题是否退步。
4. **每个候选都按同一口径验证。** 固定 30 题、同一模型与生成参数，记录完整消息、模型版本、使用的片段、输出及耗时。分别报告执行失败、词面 F1、拒答、引用支持与人工/AI复核性质；通过后扩大到原 80 题及新论文样本。

本轮得到的是错误定位及可复现证据，尚未产生新的回答提升分数。业务默认值和正式提示词保持当前验收版本。
