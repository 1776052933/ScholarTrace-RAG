# 中文辅助复核

`m6_zh_translations.json` 为 2026-10-17 缓存的 44 条回答提供中文阅读辅助，包含
22 道问题、40 段不同的回答、49 段不同的引用和 2 个文字标注候选。
相同原文共享译文；中文回答保留原样。原文 SHA-256 必须完全匹配才显示译文，
新回答或修改后的证据不会套用旧翻译。

译文由 AI 离线辅助编写，页面不调用翻译模型。数字、模型名及原文矛盾保留；
原始解析中的表格缺项、串栏、截断不代表 PDF 本身如此，核对时应打开原文和 PDF。
译文不能作为独立标准答案，也不能替代复核者的判断。

## 操作

1. 选择题目，阅读中文问题与模型回答。
2. 对照中文引用、可展开的原始摘录和右侧 PDF，分别判断答案事实及引用支持。
   表格题要核对行、列、数字和页码。无法确认时保留“无法判断 / 待复核”。
3. 填写复核人、必要的错误类型和备注，点击“保存本题”。默认只显示未完成项；
   取消该选项可以修改已保存判断。

系统不自动生成评分；原 CSV 仍使用空值、yes、no。启动和切题不会修改评分。
自动排查提示默认关闭，主动开启后也只是线索。报告本批结果时应注明
“机器翻译辅助的人工复核”，不要写为独立双语专家核验。

从仓库根目录运行：

```console
python -m streamlit run evaluation/m6_review_ui.py --server.port 18506
```

需要本机已有缓存回答、复核 CSV 和 manifest 所指向的 PDF；本目录的翻译文件
不包含整篇论文译文。用户评分继续存放在原复核 CSV 中。
