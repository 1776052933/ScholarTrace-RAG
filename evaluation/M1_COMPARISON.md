# M1 与 M0 固定十题对照（2026-10-15）

## 对照条件

两轮均使用 QASPER v0.3 dev、`--limit 10 --seed 42 --top-k 5`，十个 question_id、数据文件 SHA256 和 BGE-M3 模型修订完全相同；均调用 `deepseek-chat`，temperature 0。M0 原始记录在 `evaluation/runs/m0_qasper_dev10/`，最终 M1 记录在 `evaluation/runs/m1_qasper_dev10_final/`。两轮的 `manifest.json` 保存各自代码指纹与依赖版本，逐题数据保存在 `records/`。这些运行目录被 Git 忽略，需在同一机器保留或自行归档。

| 指标 | M0 | M1 最终 | 解释 |
| --- | ---: | ---: | --- |
| 成功题数 | 10/10 | 10/10 | 两轮均无失败题 |
| 证据召回代理值 | 0.667 | 0.667 | 对 8 道有人工证据的题目求宏平均；无可测提升 |
| 回答词级 F1 代理值 | 0.176 | 0.165 | 词面匹配受语言和生成波动影响；不能当语义正确率 |

| 逐题总耗时 | 140.1 秒 | 137.9 秒 | CPU 单次运行差异，不能断言性能收益 |
| 入库耗时 | 124.3 秒 | 123.3 秒 | 同上 |
| DeepSeek token | 14,002 | 14,135 | 模型输出 token 有波动 |

M1 的十条回答都生成了结构化 `citations`，每条包含论文 ID、chunk ID、标题、章节、原文和可用时的 PDF 页码。QASPER 使用结构化全文，`page=null` 是正确结果；PDF 页码由两页真实 PDF 的端到端回归测试验证，第二页证据返回 `page=2`。索引测试验证了持久化后模型指纹与维度仍能检查，错误模型或无版本旧向量会被拒绝。相关离线回归 60 项通过。

## 结论与后续评估

版本归档和 M1 工程验收见 [`docs/VERSION_ARCHIVE_AND_M1_ACCEPTANCE.md`](../docs/VERSION_ARCHIVE_AND_M1_ACCEPTANCE.md)。原始 M0 的运行数据已保存，但从初始提交重建的 M0 源码指纹与当次运行记录不一致，不能将重建分支视为精确复现。


M1 完成的是正确性和代码边界改造。此十题样本没有证明问答质量提升；词级 F1 甚至略低，不能作为优化收益宣传。后续 M3 的混合检索和重排应继续用相同题目与更大的开发集测证据召回，并报告耗时与 token。PDF 页码定位需要单独的人工页码金标准集，M6 再报告引用支持率、拒答准确率和完整测试集成绩。

旧 Chroma `paper_chunks` 不会自动混入新的 `paper_chunks_m1`；升级后须重新摄取论文。完整 LitSearch 固定 64,183 篇的正式成绩仍未运行，已有小样本仅验证流程。实时学术 API 搜索与固定语料检索继续分开报告。
